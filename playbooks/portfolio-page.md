# Portfolio Page Playbook

## 목적
포트폴리오 페이지는 단순 숫자 갱신이 아니라 **현재 포지션의 의미와 시장 맥락**이 드러나게 유지한다.

## 기본 원칙
- 총자산/수익률 숫자만 맞추지 말고, 핵심 포지션 변화의 의미를 반영한다.
- 큰 시장 변화가 있으면 페이지 설명/주석도 같이 업데이트한다.
- 숫자 이상치가 나오면 자동 반영 전에 한 번 의심한다.

## 우선 반영 항목
1. 총 자산
2. 수익률
3. 주요 보유종목 비중 변화
4. 핵심 포지션 논리 변화
5. 지정학/유가/환율이 포트폴리오에 미치는 영향

## 업데이트 기준
### 바로 반영
- 자산 총액/수익률 변경
- 주요 종목 비중 변화
- 페이지 깨짐/배포 오류 수정

### 설명까지 같이 손볼 것
- 반도체/방산/조선/전력 같은 핵심 축의 논리가 바뀔 때
- 지정학 리스크가 커져 포트폴리오 해석이 달라질 때
- 시장 스타일이 성장 → 방어 또는 반대로 바뀔 때

## 출력 원칙
- 현재 포트폴리오의 핵심 축 2~4개를 한 줄씩 설명 가능해야 함
- 숫자보다 구조 변화가 더 중요하면 그걸 우선 표기
- 과장된 낙관/비관 금지

## 배포 원칙
- 업데이트 후 링크 확인
- 오류 시 프리뷰 링크라도 확보
- 사용자가 바로 열 수 있는 고정 링크를 우선 안내
