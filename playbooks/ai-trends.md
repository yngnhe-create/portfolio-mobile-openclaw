# AI Trends Playbook

## 목적
AI 트렌드를 단순 화제성으로 소비하지 말고, **실제 산업 변화 / 제품화 / 투자 의미** 중심으로 해석한다.

## 핵심 질문
- 이게 진짜 구조 변화인가, 일시적 hype인가?
- 실제 사용자 행동이나 개발 워크플로우를 바꾸는가?
- 기업/생태계/오픈소스 경쟁 구도에 어떤 영향을 주는가?
- 네 OpenClaw 활용 방식과 연결되는가?

## 우선 감시 대상
1. 모델 성능/가격 변화
2. 에이전트/브라우저 자동화/툴 사용 능력
3. 메모리, world model, embodied AI
4. 오픈소스/로컬 모델 생태계
5. OpenClaw / Codex / Claude / Gemini 실사용 흐름
6. 규제, 프라이버시, 보안 이슈

## 소스 우선순위
- OpenClaw 커뮤니티 / 레딧
- 주요 연구 발표 / 제품 릴리즈
- 빅테크 공식 발표
- 실사용자 후기와 벤치마크

## 구분 기준
### 진짜 중요한 변화
- 가격 대비 성능이 크게 달라짐
- 기존 워크플로우를 대체할 정도의 실용성
- API/툴 사용 방식이 바뀜
- 로봇/에이전트/브라우저 자동화 수준이 한 단계 올라감

### 참고만 할 변화
- 단순 벤치 1위 경쟁
- 데모는 화려하지만 재현성 낮은 발표
- 커뮤니티 밈/팬심 중심 반응
- 일시적 과열 종목/토큰 언급

## OpenClaw 관점에서 중요하게 볼 것
- 브라우저 자동화 실사용성
- 멀티채널/메모리/에이전트 운영 방식
- Codex/Claude/Opus/Sonnet 사용성 변화
- 프라이버시/로컬 실행 대안

## 출력 형식
- 오늘의 진짜 변화 1~3개
- 왜 중요한지
- OpenClaw/실사용 관점 의미
- hype인지 구조 변화인지 판단

## 톤
- 과장 줄이기
- 제품/사용자 행동 변화 중심
- 투자 아이디어와 연결되면 별도로 표시
