# WiseReport Automation Playbook

## 목적
와이즈리포트 자동화는 단순 스크래핑이 아니라 **로그인 안정성 + 의미 있는 변화 추출**에 초점을 둔다.

## 핵심 원칙
- 목표는 모든 텍스트 수집이 아니라, Today Top/Hot/Best, 목표가 변화, 신규 커버리지, 섹터 흐름을 안정적으로 추출하는 것
- anti-bot 우회보다 로그인/팝업/DOM 변화 대응이 우선
- Report Summary 기준을 기본으로 삼는다

## 자동화 체크포인트
1. 로그인 성공 여부
2. 중복 로그인 팝업 처리
3. 기업 탭 / 산업 탭 전환 확인
4. Today Top/Hot/Best 확보
5. 목표주가 상향/하향/신규 커버리지 확보
6. 총 리포트 수와 섹터 분포 확인

## 실패 시 우선 확인
- 로그인 폼 구조 변경
- 팝업 버튼 셀렉터 변경
- Summary 테이블 DOM 변경
- 세션 만료

## 리포트 작성 원칙
- Executive Summary를 항상 먼저 작성
- 숫자 나열보다 오늘 시장의 3대 축을 먼저 추출
- 국내 증권사 / 네이버 리서치 / 외국계 시각을 가능하면 교차 확인

## 안정성 규칙
- 페이지 전체보다 핵심 블록 우선 수집
- 실패 시 부분 성공 데이터라도 활용
- DOM이 바뀌어도 핵심 요약은 유지되게 설계
