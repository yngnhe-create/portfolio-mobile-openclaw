# WiseReport Playbook

## 목적
WiseReport를 단순 복붙하지 말고, **시장 자금 흐름과 의미 있는 리레이팅 변화**를 읽어내는 분석 보고서로 만든다.

## 기본 절차
1. WiseReport 직접 로그인
2. Report Summary 기준 데이터 수집
3. Today Top / Hot / Best 확인
4. 목표주가 상향/하향, 신규 커버리지 정리
5. 산업/섹터 리포트 확인
6. 네이버 금융 리서치와 교차 확인
7. 외국계 증권사/글로벌 IB 시각과 연결
8. Executive Summary 먼저 작성

## 가장 중요하게 볼 것
### 1. 목표주가 숫자보다 논리 변화
- 왜 올렸는지/내렸는지
- 단순 실적 추정 조정인지
- 스토리 자체가 바뀌는지
- 장기 성장 서사가 붙는지

### 2. 여러 증권사가 같은 방향을 볼 때
- 국내 여러 하우스가 같은 테마를 밀면 중요도 상승
- 국내 + 외국계 논리가 겹치면 더 중요

### 3. Today Top/Hot/Best의 의미
- 단순 인기보다 **오늘 시장이 어디에 시선을 두는지** 해석
- 성장주 / AI 인프라 / 밸류업 / 지정학 수혜 중 어느 축인지 분류

### 4. 신규 커버리지
- 시장에서 새롭게 보기 시작한 종목은 별도 주목
- 특히 업황 전환기/정책 수혜/주주환원 축이면 중요도 상승

## 분석 프레임
종목은 아래 4개 축 중 어디에 속하는지 먼저 분류:
- 반도체 / AI 인프라
- 밸류업 / 주주환원
- 지정학 수혜 (방산/조선/전력)
- 구조 변화 / 턴어라운드

## 출력 형식
1. Executive Summary
2. Today Top / Hot / Best 해석
3. 목표주가 변경 핵심 종목
4. 섹터별 자금 흐름
5. 국내 증권사 vs 외국계 시각 비교
6. 액션형 결론 (매수관찰 / 보유 / 단기체크)

## 강조할 것
- 오늘 시장의 3대 축이 무엇인지
- 어떤 종목이 **확신형 주도주**인지
- 어떤 종목이 **스토리 회복형**인지
- 어떤 종목이 **밸류업/재평가형**인지

## 경계할 것
- 목표주가 상향만 보고 무조건 긍정 해석하지 않기
- 리포트 문구 과장에 휘둘리지 않기
- 하루치 인기 종목을 장기 주도주처럼 과대평가하지 않기
- 숫자보다 구조 변화 여부를 우선하기

## 톤
- 한국어
- 전문적이되 딱딱하지 않게
- 투자 판단 보조용
- 표와 요약 적극 활용
