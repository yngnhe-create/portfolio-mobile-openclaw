# News Briefing Playbook

## 목적
최신 뉴스를 단순 나열하지 말고, **중요도와 파급력 중심**으로 짧고 실용적으로 브리핑한다.

## 기본 원칙
- 속보를 다 담지 말고 **시장/일정/생활에 영향 있는 것만** 우선한다.
- 같은 내용 반복 보도는 묶어서 1개 이슈로 요약한다.
- 기사 자체보다 **왜 중요한지**를 한 줄로 설명한다.
- 과장된 제목보다 사실관계와 파급효과를 우선한다.

## 우선순위
1. 지정학/전쟁/에너지
2. 한국 증시와 환율에 직접 영향 주는 거시 뉴스
3. AI/반도체/플랫폼 산업 변화
4. 사용자 관심사와 직접 연결된 뉴스
5. 일반 국제/사회 뉴스

## 브리핑 형식
기본 4개 섹션:
- 국제
- 한국
- AI
- 증시

형식 규칙:
- 텔레그램에서 읽기 쉽게 불릿 위주
- 너무 길게 쓰지 않기
- 맨 위에 정말 중요한 속보가 있으면 `🚨 한 줄 속보` 추가
- 각 섹션은 2~4개 포인트 내로 유지
- 정기 브리핑은 **하루 3회 정도면 충분**하다는 전제로 압축
- 새로울 게 없으면 섹션 수를 줄이고 짧게 끝낼 것

## 알림 기준
### 바로 알릴 것
- 전쟁/유가/환율 급변
- 한국시장에 직접 충격 주는 정책/사건
- 빅테크/AI 모델 출시 중 의미 큰 것
- 사용자 보유/관심 자산에 직접 영향 주는 뉴스

### 정기 브리핑으로만 보낼 것
- 반복되는 일반 헤드라인
- 중요하지만 즉시 행동이 필요 없는 뉴스
- 커뮤니티 화제성만 있는 AI 소식

### 생략할 것
- 클릭 유도형 기사
- 사실 확인이 약한 루머
- 같은 사건의 중복 기사
- 한국/시장/AI와 연결고리가 약한 단순 화제 뉴스
- **직전 브리핑과 실질적으로 달라진 점이 없는 업데이트**

## 중복 억제 규칙
- 직전 브리핑과 핵심 포인트가 거의 같으면 길게 보내지 말 것
- 새 사실/새 숫자/새 결정/새 충격이 없으면 `큰 변화 없음` 1~3줄 요약만 보낼 것
- 같은 이슈는 후속 정보가 생겼을 때만 다시 상단 배치
- AI 섹션은 실사용/가격/정책/모델 변화가 없으면 과감히 생략 가능
- 지정학 뉴스는 헤드라인 반복보다 **유가/환율/한국시장 영향의 변화**가 있을 때만 비중 확대

## 톤
- 짧고 담백하게
- 호들갑 금지
- 핵심 → 의미 → 영향 순서
- 불확실하면 확신하지 말고 `초기 보도` 또는 `추가 확인 필요`로 표시
