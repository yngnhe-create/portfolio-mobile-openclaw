# Strategy Playbooks

이 디렉토리는 OpenClaw를 개인 전략실처럼 운영하기 위한 판단 기준 모음이다.

## 현재 플레이북
- `news-briefing.md` — 뉴스 브리핑 우선순위와 형식
- `wisereport.md` — 와이즈리포트 해석 프레임
- `wisereport-automation.md` — 와이즈리포트 자동화 안정성 기준
- `geopolitics.md` — 지정학/유가/환율/한국시장 영향 프레임
- `portfolio.md` — 보유종목/관심종목 해석 기준
- `portfolio-page.md` — 포트폴리오 페이지 업데이트 기준
- `ai-trends.md` — AI 트렌드와 hype 구분 기준
- `reddit-ai-briefing.md` — 레딧/커뮤니티 AI 브리핑 기준
- `alert-priority.md` — 즉시 알림 / 정기 브리핑 / 무시 규칙

## 운영 원칙
1. 플레이북은 즉흥 답변보다 우선한다.
2. 같은 주제의 자동화/브리핑/페이지 업데이트는 해당 플레이북을 먼저 참고한다.
3. 중요도는 `alert-priority.md`를 따른다.
4. heartbeat와 cron은 플레이북 기반으로만 감시/준비 작업을 수행한다.
