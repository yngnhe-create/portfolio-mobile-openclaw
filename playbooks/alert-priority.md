# Alert Priority Rules

## 목적
알림을 많이 보내는 것보다 **정말 의미 있는 변화만** 보내서 신뢰도를 유지한다.

## 우선순위 레벨

### P1 — 즉시 알림
바로 보내야 하는 것
- 보유/관심 종목 임계가 도달
- 한국시장 개장 전에 큰 영향을 줄 중대 뉴스
- 지정학 확전, 호르무즈 실질 봉쇄, 유가 급등
- 일정/회의/행동이 필요한 급한 이벤트
- 페이지/자동화 실패 중 중요한 것

### P2 — 정기 브리핑 포함
중요하지만 즉시 행동 필요는 없는 것
- 주요 증권사 리포트 변화
- AI 업계 중요한 업데이트
- 시장 흐름 변화
- 레딧/커뮤니티 주요 트렌드

### P3 — 보관만
기록은 하되 굳이 알릴 필요는 없는 것
- 반복되는 일반 뉴스
- 비슷한 내용의 중복 기사
- 중요도 낮은 커뮤니티 화제
- 행동으로 이어지지 않는 잡음

## 시간 규칙
- 00:00~08:00: 긴급한 P1 아니면 보내지 않음
- 08:00~23:00: 정상 브리핑/알림 가능
- 심야엔 테스트 메시지 금지

## 반복 방지 규칙
- 같은 이슈 재알림 금지
- 의미 있는 새로운 정보가 생겼을 때만 후속 알림
- 가격 알림은 이전 알림 대비 materially changed 일 때만 재전송

## 채널 규칙
- 메인 대화/일반 브리핑: 텔레그램
- 게시/보관/주제별 알림: 디스코드
- 같은 내용을 양쪽에 중복 발송하지 않기

## 작성 규칙
- 한 줄 요약 먼저
- 왜 중요한지 한 줄
- 필요하면 링크/페이지 경로 추가
- 공포/과장 금지

## 예외
- 사용자 요청이 있으면 P2/P3도 즉시 정리 가능
- 수동 요청은 자동 우선순위보다 항상 우선
