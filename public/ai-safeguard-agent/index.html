AI SAFEGUARD AGENT · PROTOTYPE

외부 AI 사용 전 민감정보를 자동 탐지·마스킹하는 보안 게이트웨이 PoC

이 프로토타입은 프롬프트 입력 → 민감정보 탐지 + 기밀 문맥 판단 → 마스킹 여부 선택 → 외부 AI 전송 직전 생성까지를 체험하는 목업이다. 실제 외부 AI 호출 대신, 보안 통제 흐름과 사용자 경험을 검증하는 데 초점을 둔다.

임직원이 외부 AI에 보내려는 문장을 입력한다. 예시 버튼을 눌러 테스트할 수 있다.
